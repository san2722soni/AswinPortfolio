# Project Summary - Halloween Calculator

**Type:** Personal curiosity project  
**Duration:** Early frontend phase  
**Priority:** Good archive project  
**Best angle:** "Not just a calculator" - themed utility app with multiple calculators, converters, and easter eggs.

## One-Line Pitch

A Halloween-themed multi-calculator built with vanilla JavaScript, including arithmetic, age, area, BMI, data, discount, length, mass, speed, temperature, currency conversion, keyboard support, and hidden easter eggs.

## What To Say In Portfolio

Built as a personal curiosity project to explore DOM-heavy JavaScript, UI state, utility logic, keyboard interaction, and playful hidden features without following a tutorial.
