# Halloween Calculator

## What It Is

Halloween Calculator is an early personal/curiosity project, not a copied tutorial calculator. It is a Halloween-themed multi-utility calculator with a normal arithmetic calculator, advanced calculator tabs, conversion tools, visual effects, keyboard support, clues, and hidden easter-egg behavior.

## What It Does

- Normal calculator with chained arithmetic, history display, temporary result display, clear, backspace, decimal handling, and keyboard input.
- Advanced calculator mode with tab-based switching between multiple tools.
- Age calculator using date input and current date comparison.
- Area calculator for square, rectangle, triangle, circle, parallelogram, trapezium, annulus, and ellipse with formula display and solution output.
- BMI calculator with sliders, BMI result, and health category coloring.
- Data converter for bytes through exabytes.
- Discount calculator with payable amount and savings calculation.
- Length, mass, speed, and temperature converters.
- Currency converter using a currency API and delayed keyup conversion.
- Halloween mode triggered through the skull icon with background/audio/number shuffle behavior.
- Tutorial popup using SweetAlert and a GIF walkthrough.
- Hidden OTP/easter egg flow that redirects to `Portfolio.html` when the right result is entered.

## My Role

Personal project built out of curiosity and experimentation. I designed the themed UI, wrote the vanilla JavaScript logic across separate modules, handled the tabbed calculator flow, added keyboard interactions, and built hidden easter eggs instead of making only a basic calculator.

## Tech Stack

Static HTML, CSS, vanilla JavaScript, Font Awesome, SweetAlert, Chart.js import, media assets, GIF/audio/image effects.

## Portfolio Value

Use as an archive/early interactive JavaScript project. It proves curiosity, DOM manipulation, event handling, modular vanilla JS files, UI state switching, utility logic, and playful product thinking.
